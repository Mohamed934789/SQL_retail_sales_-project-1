# Retail Sales SQL — learning project

SQL Server queries over the supplied retail CSV: aggregates, CTEs, window rankings and time groups.
Create/import the table described in `schema.sql`, mapping the original `quantiy` header explicitly,
then run `SQLQuery_Project_1 .sql`. The malformed average-age alias, mixed table names, ambiguous
date literal and gender/category grouping are corrected. Monthly ranking is labelled as total sales,
not an average. Rows with missing values are reported for review; analysis does not delete them.
No live database execution or benchmark result is claimed. This is supporting SQL learning work.
